# Simple OTC Desk v2

Демонстрационный OTC-деск на FastAPI и SQLite.

## Добавлено

- RFQ можно создать от количества криптовалюты или от суммы фиата;
- после ввода цены автоматически рассчитывается вторая сторона сделки;
- комиссия OTC удалена;
- добавлены комиссия банка и комиссия сети;
- безопасное принятие котировки с защитой от повторного принятия;
- сводный HTML-отчет и экспорт CSV;
- автоматическое добавление новых колонок в старую SQLite-базу.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть: http://127.0.0.1:8000

## Важно

Это демонстрационный MVP, не production-система.


## Изменения v3

- Поле фиатной валюты больше не предзаполняется значением USDT.
- Валюта банковской комиссии берется из quote asset пары RFQ.
- В сводном отчете удалены агрегированные итоги по валютам; показывается только перечень сделок.

## Изменения v5

- В карточке сделки история статусов показывает дату и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.
- В сводном HTML- и CSV-отчете добавлены отдельные столбцы даты и времени для каждого статуса сделки.
- Комиссия банка и комиссия сети отображаются отдельными столбцами с валютами из торговой пары.
