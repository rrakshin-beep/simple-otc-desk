# Simple OTC Desk

Учебный MVP для учета внебиржевых криптовалютных сделок.

## Возможности
- создание RFQ;
- выставление котировки дилером;
- принятие котировки клиентом;
- создание сделки;
- контролируемые переходы статусов;
- расчет стоимости и комиссии;
- журнал истории сделки;
- простой JSON API `GET /api/trades`.

## Запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
Открыть: http://127.0.0.1:8000

## Важно
Это демонстрационный код, не production-система. До реального использования необходимы авторизация, RBAC, 2FA, double-entry ledger, идемпотентность, транзакционные блокировки, AML/KYC, защита секретов, интеграция с custody/HSM/MPC, аудит безопасности и юридическая проверка.
