# OTC Desk 3.0

Рабочий прототип OTC-деска на FastAPI, SQLAlchemy, SQLite и Jinja2.

## Основные модули

- кабинет клиента: создание RFQ, просмотр, принятие и отклонение котировок;
- кабинет дилера: создание запросов для котирования, выставление котировок и сопровождение сделок;
- кабинет комплаенса: контрагенты, профиль подотчетного лица, Форма 1, валидация и XML;
- сводный отчет, CSV и XLSX;
- НСИ АРМ ФУС из XML-справочников.

## Новое в версии 3.0

- полная выгрузка блока `ADDINFO` юридического лица;
- основной и дополнительные виды деятельности;
- блок `DISPONENT` для лица, уполномоченного распоряжаться счетом;
- код, серия, номер, дата выдачи и орган выдачи документа уполномоченного лица;
- трехзначные коды документов из `doc_codes.xml`;
- сохранение и редактирование новых полей контрагента;
- автоматическая миграция существующей SQLite-базы;
- проверка кодов документов по справочнику;
- генерация XML в `windows-1251` в порядке тегов, ожидаемом АРМ ФУС.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Открыть: `http://127.0.0.1:8000`

## Railway

Start Command:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Проект также содержит Dockerfile.

## Важно

Перед обновлением сохраните резервную копию `otc.db`. Проект является прототипом: перед промышленной эксплуатацией требуются авторизация, RBAC, PostgreSQL, защищенный аудит и проверка актуальной НСИ СФР КР.
