# Обновление существующего репозитория

1. Сохраните резервную копию текущего `otc.db`.
2. Скопируйте содержимое этой папки в корень репозитория `simple-otc-desk` — не копируйте саму внешнюю папку `OTC-Desk-2.0`.
3. Выполните:

```bash
git add .
git commit -m "Upgrade to OTC Desk 2.0"
git push origin main
```

4. Railway автоматически выполнит новый deployment.
5. После запуска заполните `/settings/reporting`, затем создайте участников в `/parties`.

Текущие таблицы сделок сохраняются. Новые таблицы создаются автоматически. Перед обновлением production-среды обязательно сделайте резервную копию базы.
